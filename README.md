## Задание 2
Самый большой объем резидентной памяти (RSS) среди доступных для просмотра процессов занимает 
**fwupd** (около 30 МБ).
Показатель RSS (Resident Set Size) отражает ту часть памяти, которая реально загружена в физическую
оперативную память (RAM) прямо сейчас. 
Показатель VSZ (Virtual Memory Size) показывает общий объем виртуального адресного пространства, 
который может быть гораздо больше RSS.
