## Задание 6
Результат: В ходе выполнения команд было установлено, что на данной виртуальной машине swap (файл подкачки) **отсутствует** (объем Swap в `free -h` равен 0, команда `swapon` не вывела активных устройств).
Swap — это область на диске, которая используется как продолжение оперативной памяти (RAM). Он отличается от RAM тем, что работает в разы медленнее (доступ к диску занимает миллисекунды, а к RAM — наносекунды). 
Использование swap может замедлять программы, потому что системе приходится постоянно считывать данные с медленного диска обратно в быструю память (этот процесс называется "трэшинг").
## Задание 7
Linux использует свободную оперативную память (RAM) для кэширования содержимого файлов (page cache). Это позволяет ускорить повторные операции чтения с диска, так как данные уже лежат в быстрой памяти. При этом сам Linux не спешит отдавать эти данные обратно на диск, а если другим программам понадобится память, ядро мгновенно освободит этот кэш.
Поэтому считается, что "свободная память — это потраченная впустую память".

**Ответы на вопросы:**

1. **Почему программа может успешно работать на хосте, но завершаться в контейнере?**
На хосте доступно много оперативной памяти, а в контейнере жестко ограничен лимит (128 МБ). При попытке выделить 200 МБ ядро Linux принудительно завершает процесс, чтобы защитить систему.

2. **Каким механизмом Linux Docker ограничивает память?**
Docker использует механизм ядра Linux — **cgroups** (control groups), который позволяет накладывать ограничения по ресурсам на группы процессов.

3. **Создаёт ли Docker отдельное виртуальное адресное пространство для каждого процесса?**
Да, каждый процесс в контейнере имеет свое виртуальное адресное пространство, изоляция достигается за счет namespaces.

4. **Чем ограничение памяти контейнера отличается от размера виртуальной памяти процесса?**
Лимит Docker (cgroup) ограничивает физическую резидентную память (RSS). Виртуальная память (VSZ) может быть огромной, но если процесс не трогает эти страницы физически, он не будет убит. Как только реальное потребление RAM превысит лимит — сработает OOM-killer.
