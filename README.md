## Задание 2
Самый большой объем резидентной памяти (RSS) среди доступных для просмотра процессов занимает 
**fwupd** (около 30 МБ).
Показатель RSS (Resident Set Size) отражает ту часть памяти, которая реально загружена в физическую
оперативную память (RAM) прямо сейчас. 
Показатель VSZ (Virtual Memory Size) показывает общий объем виртуального адресного пространства, 
который может быть гораздо больше RSS.

## Задание 4
При увеличении объёма выделенной памяти в Python показатель RSS (Resident Set Size) растёт. 
Это происходит потому, что программа не просто резервирует виртуальную память, а активно записывает данные в каждую страницу (цикл `block[j] = 1`), заставляя операционную систему выделять реальные физические блоки в оперативной памяти (RAM).
## Задание 5

ОС забирает память обратно только в крайнем случае.
